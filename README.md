\# UDMS Image Classifier



\## What is this project?

An AI-powered image classification module for the Urban Disorder 

Monitoring System (UDMS). It automatically categories 

citizen-submitted photos of urban issues into 7 categories.



\## Categories

1\. Illegal Dumping / Garbage

2\. Pothole / Road Damage

3\. Broken / Missing Street Lighting

4\. Water / Sewage Issues

5\. Damaged Signage / Infrastructure

6\. Vegetation Overgrowth

7\. Other / Unclassified



\## Project Structure

\- data/        → training images

\- notebooks/   → model training (Google Colab)

\- app/         → REST API microservice

\- models/      → trained model files

\- docs/        → documentation

\- tests/       → test files
